# Escala de Rotas Inteligente — By Copetti

Estrutura correta para deploy no Vercel:

- index.html
- vercel.json
- logo-via.png opcional

No Vercel:
1. Suba estes arquivos na raiz do projeto.
2. Framework Preset: Other.
3. Build Command: deixe vazio.
4. Output Directory: deixe vazio ou use ".".
5. Deploy.

Depois de abrir o site, configure a URL base do n8n no campo lateral.
